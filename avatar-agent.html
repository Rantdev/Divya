3D Avatar Agent

A real-time voice customer support agent you talk to in the browser. It answers questions from a company’s own documents, so replies are grounded in real policies rather than generic model knowledge. Customers can interrupt it mid-sentence, as on a phone call. An optional 3D avatar gives support a face, and without it the page shows a voice bubble that moves with the agent’s voice. The RAG pipeline is built as a reusable module, so the same code can serve a different business by swapping the documents and one config file.

The three components

RAG(Qdrant + fastembed) —The knowledge layer. Company documents are loaded, split into chunks, embedded with fastembed and stored in Qdrant. The agent has a single retrieval tool and answers only from what it returns, and says so when it doesn’t know. The pipeline uses abstract contracts for the embedder and vector store, plus stable chunk IDs, so re-ingesting a file replaces its chunks instead of duplicating them.
LiveKit (real-time voice)— The conversation layer. LiveKit provides the WebRTC rooms and runs the Python agent. Speech-to-text, the LLM (Groq) and text-to-speech are chained with streaming, and turn detection and interruption handling make the conversation feel natural. A React frontend shows the video on the left and the live transcript on the right.
Beyond Presence (3D avatar) — The presentation layer. The avatar joins the same room as another participant, receives the agent’s speech and publishes lip-synced video. It is switched on or off with one setting and requires no frontend changes.
